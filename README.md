# 🏨 Projet DUCSMAN — Site d’hôtel de luxe

## 📖 Présentation

**DUCSMAN** est un site vitrine haut de gamme pour un hôtel 5 étoiles basé à Paris.  
Le projet met l’accent sur une **expérience utilisateur élégante**, un **design responsive**, et une **navigation fluide** à travers plusieurs pages : accueil, chambres, contact, et autres services de l’hôtel.

Ce projet a été conçu en **HTML5**, **CSS3 (SASS)** et **JavaScript**, dans le cadre d’un **projet de groupe** visant à reproduire une interface professionnelle et réaliste d’un site hôtelier de luxe.

## 🧩 Structure du projet

```
Projet-groupe-Ducman/
├── index.html          # Page d’accueil
├── chambre.html        # Page des chambres et suites
├── contact.html        # Page de contact
├── assets/
│   ├── images/         # Logos, icônes, photos de l’hôtel
│   ├── js/
│   │   └── script.js   # Scripts d’interaction (menu, responsive, etc.)
│   └── sass/
│       ├── main.css    # Feuille de style principale compilée
│       └── vendors/    # Fichiers CSS externes (normalize, flaticons, themify)
└── README.md
```

## 💡 Fonctionnalités principales

- Menu latéral interactif avec navigation fluide entre les pages
- Design responsive (desktop, tablette, mobile)
- Page d’accueil immersive avec présentation du concept hôtelier
- Page "Chambres & Suites" décrivant les offres, aménagements et services
- Formulaire de contact complet (nom, email, message)

## 🛠️ Technologies utilisées

- HTML5
- CSS3 / SASS
- JavaScript
- Outils externes : Flaticons, Themify, Normalize.css
